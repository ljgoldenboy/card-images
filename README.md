# card-images

Картинки для карточек сводок: баннеры, плашки, графики.

Правила:

- файл кладётся один раз; в имени дата, тема и номер выпуска;
- файлы не переименовываются, не переносятся и не удаляются;
- история не переписывается, репозиторий не переименовывается.

На файлы стоят постоянные ссылки с номером коммита. Любое из действий выше сломает картинки в карточках.
